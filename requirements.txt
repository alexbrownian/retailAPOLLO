# retailAPOLLO runtime dependencies.
#
# This file is what the HOSTED dashboard installs: Streamlit Community
# Cloud reads requirements.txt automatically and has no setting to point
# at another name. So it carries only what a machine needs to RUN the
# pipeline and draw the dashboard - nothing that exists for notebooks,
# tests, or a Windows corporate network. Research and workstation extras
# live in tools/requirements-dev.txt.
#
# Workstation (both machines):
#   pip install -r requirements.txt -r tools/requirements-dev.txt --user
#
# Hosted dashboard: installs this file only, automatically.
#
# WINDOWS: --user is not cosmetic. Installing into a system Python
# (C:\Python312\) makes pip rewrite files under Scripts\ and
# site-packages\, and an upgrade of an already-present transitive
# dependency then fails mid-uninstall:
#
#   WARNING: Failed to write executable - trying to use .deleteme logic
#   ERROR: ... [WinError 2] The system cannot find the file specified:
#          'C:\Python312\Scripts\<name>.exe' -> '<name>.exe.deleteme'
#
# pip rolls the change back, so the environment survives, but nothing is
# installed. Two causes, both worth clearing before a reinstall:
#   * a running process holds the files - stop Streamlit and any Jupyter
#     kernel first; a live dashboard keeps site-packages open;
#   * no write permission to the system Python - --user installs into the
#     per-user directory and avoids it entirely.
# Failing both, an elevated shell (Run as administrator) works without
# --user.
